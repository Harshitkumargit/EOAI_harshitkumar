How the result was made

Why this sensor fits the question

Sentinel-2 red and near-infrared surface reflectance support NDVI directly. The pipeline applies explicit asset scale/offset metadata, masks SCL classes outside vegetation and bare land, aligns every scene to a 20 m UTM grid, and tracks usable area. Clouds still remove observations; seasonal land-cover changes can resemble crop problems. No crop-specific mask or field stress labels are available.

Would an officer act on this today?

This is an inspection-planning prototype, not a validated crop-stress diagnosis. An officer should combine it with local knowledge and first validate flagged cells. Operational use requires field feedback, crop and official boundary data, more independent seasons, publication-latency checks, drift monitoring and reliable refresh alerts. The historical replay is not a current advisory.

Evaluation and limitations

Training and test seasons are separated by target week. No future interpolation is used, and only observed targets are scored. A separate final model refits on completed historical labels after evaluation. The same cells occur in both seasons, so results do not establish geographic transfer. NDVI can saturate; haze, soil, mixed pixels, crop rotations and harvesting can confound the signal. Missing cloudy weeks are selectively absent from evaluation. The skill interval resamples four-week time blocks and is not an individual-cell prediction interval.

Source: contains modified Copernicus Sentinel data, retrieved through Element 84 Earth Search. Configuration and all parameters are recorded in the manifest. Synthetic runs use no satellite observations.
